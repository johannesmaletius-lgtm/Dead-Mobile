# Dead Mobile

Stealth-Horror-Browsergame: Ein Polizist, eine verlassene Schule, ein geschminkter Killer. Aufgaben erledigen, unentdeckt bleiben, durchs Tor entkommen.

Läuft komplett im Browser, einfach `index.html` öffnen (Handy: quer spielen).

## Aufbau

- `index.html` – Seite und Ladereihenfolge der Skripte
- `css/style.css` – Gestaltung
- `js/*.js` – Spielcode, nach Themen aufgeteilt (Karte, Killer-KI, Aufgaben, Zeichnen …)
- `tools/regress.js` – Regressionstest (Playwright)
- `docs/` – Plan für den Team-Modus und Kartenformat

Details für Entwickler und KI-Agenten: `CLAUDE.md`.
